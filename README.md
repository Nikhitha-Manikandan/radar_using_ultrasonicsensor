# Radar Using Ultrasonic Sensor and Arduino

## Project Overview
This project demonstrates a radar-like scanning system using an Arduino and an ultrasonic sensor. It detects objects and visualizes their positions using the Processing application on a computer.

## Technologies Used
- Arduino
- Ultrasonic Sensor
- Processing
- Arduino IDE

## Project Files
- `radar_ultrasonic.ino` – Arduino source code.
- `radar_ultrasonic.pde` – Processing visualization code.

## Working Principle
The ultrasonic sensor measures the distance to objects while the system scans its surroundings. The Arduino communicates the sensor readings to the computer, where Processing displays the readings in a radar-style interface.
